# 🎟️ Генератор экзаменационных билетов

Небольшое консольное приложение, которое случайно назначает студенту билет
и надёжно добавляет результат в Excel-журнал.

![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?logo=python&logoColor=white)
![Excel](https://img.shields.io/badge/Журнал-.xlsx-217346?logo=microsoftexcel&logoColor=white)
![Tests](https://img.shields.io/badge/Тесты-unittest-2ea44f)

</div>

## ✨ Возможности

- Запрашивает фамилию и имя, удаляет пробелы по краям и не принимает пустые поля.
- Выбирает случайный билет **от 1 до 20 включительно**.
- Показывает номер билета в консоли и записывает его в `journal.xlsx`.
- Создаёт Excel-файл с заголовками при первом запуске; при следующих запусках
  добавляет новые записи, не перезаписывая старые.
- Сохраняет каждую запись сразу. Обновление выполняется через временный файл,
  поэтому неудачная запись не повреждает предыдущий журнал.
- Завершает работу по **Esc** во время ожидания ввода.
- При недоступном файле предлагает закрыть его в Excel и повторить сохранение.

## 🚀 Быстрый запуск

Нужен Python **3.10 или новее**.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python ticket_generator.py
```

В Linux или macOS активируйте окружение командой `source .venv/bin/activate`.

## 🖥️ Пример работы

```text
Для выхода нажмите ESC.
Last name: Иванов
First name: Иван
Билет № 7.
Запись сохранена в journal.xlsx.
```

При первом запуске рядом с приложением появится `journal.xlsx` с колонками:

| Last name | First name | Номер билета | Дата и время |
|---|---|---:|---|
| Иванов | Иван | 7 | 2026-10-21 12:30:00 |

Нажатие Enter на пустом поле покажет сообщение об ошибке и повторит запрос.
Чтобы закрыть приложение, нажмите Esc во время ввода фамилии или имени.

## ✅ Проверки и тесты

Проверки охватывают заполнение имён, диапазон билетов, ввод с Esc и Backspace,
создание и повторное заполнение Excel-журнала, проверку его структуры и
сохранность исходного файла при ошибке записи.

```powershell
python -m unittest discover -s tests -v
```

Те же тесты запускаются автоматически в GitHub Actions при push и pull request.

## 🧩 Как устроено

- `ticket_generator.py` — ввод, валидация, генерация номера и работа с Excel.
- `tests/test_ticket_generator.py` — модульные тесты без ручного ввода.
- `.github/workflows/tests.yml` — автоматический запуск тестов на GitHub.

## 📋 Соответствие заданию

| Требование | Реализация |
|---|---|
| Консольный интерфейс и выход по Esc | Ввод обрабатывает Esc, Enter и Backspace |
| Номер билета от 1 до 20 | Границы включены и проверяются тестом |
| Excel-файл с четырьмя колонками | Создаётся `journal.xlsx` с заданной шапкой |
| Записи сохраняются и дополняются | Каждая запись сохраняется сразу; строки не заменяются |
| Пустой ввод не принимается | Пробелы обрезаются, пустые значения отклоняются |
| Ошибка блокировки Excel-файла | Понятное сообщение и повтор сохранения той же записи |

## 💡 Идеи для развития

В рамках исходного задания приложение намеренно остаётся консольным. Позже можно
добавить сводку по выданным билетам, экспорт CSV или проверку повторной выдачи
билетов — не меняя базовый сценарий лабораторной работы.
